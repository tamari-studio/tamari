# Glossary

> One line per word, in the meaning it has *here*. Add a word the first time a new colleague or an
> assistant has to ask. Part of [[07-Maps/Team]].

| Word | What we mean by it |
|------|--------------------|
| Piece | One article, newsletter or post. It has a draft in Tamari. |
| Notes | The rough material a piece grows from: bullets, a transcript, a first attempt. |
| Style guide | The text that describes one voice. It is kept in the Writer space and picked for each piece. |
| Voice | How a place sounds: its rhythm, its words, how it addresses the reader. |
| Draft | A piece that is still being worked on. |
| Final | A piece nobody will change any more. It is the text that gets published. |
| Gap | A fact the notes did not hold. The draft marks it `[NEEDS: ...]` and leaves it for a person. |
| Lede | The opening paragraph: what happened and why it matters, before anything else. |
| Reader | The one colleague who checks a piece before it goes out. Not the same person as the author. |
| Source | Where a fact comes from: a person, a document or a link we can point to. |
