# Glossary

> One line per word, in the meaning it has *here*. Add a word the first time a new colleague or an
> assistant has to ask. Part of [[07-Maps/Team]].

| Word | What we mean by it |
|------|--------------------|
| Request | Something a customer or a colleague asked for, with the problem behind it. It has a row in Tamari. |
| +1 | One more person asked for the same thing. |
| New | A request nobody has decided on yet. |
| Planned | We will build it, but have not started. |
| In progress | Someone is building it now. |
| Shipped | It is live for customers, and the people who asked have been told. |
| Not now | We decided not to build it for now, and said why. |
| Roadmap | What is in progress, planned and shipped, and the space in Tamari that shows it. |
| Brief | One page that says what problem a feature solves before we build it. |
