---
name: wrap-up
description: Close a session by logging what changed and committing it. Use at the end of a session, or when the owner says "wrap up".
---

1. Append one line per change worth remembering to `log.md` (newest first).
2. Move finished projects to `08-Archive/`, and fix the links in `07-Maps/Home.md`.
3. Bump `updated` in each note you edited.
4. Commit with explicit paths (`git add <paths>`), never `git add -A`. Say what was committed.
