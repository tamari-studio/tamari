description: Capture a new permanent note in the right PARA folder with correct frontmatter. Use when the owner says "note this", "save this idea" or hands over text to keep.
---

1. Pick the folder from the map in `AGENTS.md`. If unsure, use `00-Inbox/`.
2. Open the file with the frontmatter block from `00-Inbox/frontmatter.md`. Set `title`, `type`, `created` and `updated` (now, UTC).
3. Link the note from the Map in `07-Maps/` that covers its topic, and link back to that Map from the note.
4. Add one line to `log.md`.
